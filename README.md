# Warning Label for Humans: One Line, Big Laugh

One funny single-line safety warning label that should come printed on every human being, written for the [Make.fun bounty](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

`main.py` writes the line to `/output/entry.txt`:

> WARNING: This human will nod along to instructions it did not hear, then ask you to repeat them. Speak slowly. Use diagrams.

Run it with `python3 main.py`.
